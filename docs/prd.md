## 핵심 비전

> "왜 틀렸는지 알고 푸는 수학"

단순 학원 소개 사이트가 아닌 **수학 학습 플랫폼**으로 성장.  
꽃꽂이처럼 기능을 하나씩 꽂아서 점점 풍성하게 키우는 구조.

---

## 수익 전략 (단계별)

### 방향 A — 현재 (학원 홍보 + 재원생 혜택)
- 사이트로 신뢰도 쌓고 신규 학생 모집
- AI 도구는 재원생 전용 혜택으로 제공
- 실제 수익: 1:1 원격 과외 수업료

### 방향 B — 중기 (외부 공개 + 구독)
- AI 도구를 외부 학생에게 유료 공개
- 월 구독료 모델 (9,900~29,900원)

### 방향 C — 장기 (B2B 선생님용)
- 다른 수학 선생님들이 쓰는 채점/관리 도구로 확장

| 대상 | 내용 |

## 기술 스택

- **배포:** Netlify (GitHub 자동 배포, main 브랜치)
- **구조:** HTML 단일 파일들 (서버 없음)
- **AI API:** Gemini API (학생 본인 키 입력 방식)
- **수식:** KaTeX
- **마크다운:** marked.js
- **이미지 크롭:** Cropper.js
- **저장:** localStorage (히스토리 최근 2개)

## 페이지 구성

### 1. index.html — 메인 소개 페이지
**역할:** 학부모/학생이 검색 → 방문 → 신뢰 → 상담 신청

**섹션:**
- Hero: "왜 틀렸는지 알고 푸는 수학" + 선생님 사진 + 상담 버튼
- 통계 바: 20년 경력, TOP 2%, 3중 시스템, 무료 시범
- 수업 특징: 트리플 코칭 시스템 6가지 카드
- 성과: 실제 학생 사례 + 최상위권 배출 명단
- 수업 방식: 5단계 프로세스 + 풀이 사고 흐름 시각화
- 수강료: 초중등 42만원 / 고등 48만원 정찰제
- AI 학습 도구: 풀이봇, 채점 AI, 오답노트(준비중) 카드
- CTA: 카카오톡 상담 버튼

---

### 2. solver.html — 수학 풀이봇
**역할:** 문제 사진 → 순방향 태깅 + 역방향 필연관계로 풀이 방향 안내

**핵심 철학 (김태경 선생님):**
- 정답을 알려주는 게 아니라 사고 과정을 안내
- 순방향: 조건 태깅 → 핵심 개념 파악
- 역방향: 결론에서 거꾸로 필연관계 추론
- 이해 어려운 부분: 예시와 패턴으로 설명

**기능:**
- Gemini API 키 입력 (localStorage 저장)
- 사진 업로드: 파일 선택 / 카메라 촬영(모바일) / Ctrl+V 붙여넣기 / 드래그앤드롭
- 이미지 크롭 (Cropper.js)
- 문제 사진 상단 sticky 고정 (스크롤해도 보임)
- 사진 탭 시 확대 모달
- KaTeX 수식 렌더링
- PDF 저장 (브라우저 인쇄)
- 최근 풀이 2개 히스토리 (localStorage, 썸네일 포함)
- 모델 선택: Gemini 3.6 Flash / 3.5 Flash-Lite / 2.5 Flash

---

### 3. grader.html — 서술형 채점 AI
**역할:** 문제+풀이가 함께 있는 사진 1장 → 5단계 채점 + 오류 분석

**5단계 채점 기준:**
- ❌ 접근 불가: 문제에 손도 못 댐
- 🔄 방향 오류: 핵심 개념/접근 방향 잘못됨
- ⚠️ 계산 실수: 방향은 맞지만 계산 오류
- ✅ 정답: 답은 맞지만 더 좋은 풀이 있음
- 🌟 모범 풀이: 답도 맞고 풀이도 완벽

**기능:**
- solver.html과 동일한 업로드/크롭/붙여넣기 기능
- 채점 결과 상단 뱃지로 크게 표시
- 오류 원인 + 올바른 방향 안내
- 문제 사진 sticky 고정
- PDF 저장
