# 연세정진수학 Strategy

> 이 문서는 헌법이다. 모든 기능 기획과 개발 결정은 이 문서에 어긋나지 않아야 한다.
> 새 기능을 추가하거나 방향을 바꿀 때 반드시 이 문서를 먼저 확인한다.

---

## 핵심 전략 한 줄

> **"AI 도구로 신뢰를 쌓고, 신뢰로 학생을 모으고, 학생으로 데이터를 쌓고, 데이터로 플랫폼을 만든다"**

---

## 교육 철학 (불변)

김태경 선생님의 수학 교육 철학. 모든 AI 도구의 설계 기준.

**순방향 태깅 → 역방향 필연관계**
```
문제를 읽으며 조건과 개념을 빠르게 태깅 (순방향)
→ 결론에서 거꾸로 각 단계의 필연성을 검증 (역방향)
→ 운이 아닌 논리로 푼다
```

**AI는 정답을 알려주지 않는다**
- 풀이봇은 방향을 안내하고 사고를 자극한다
- 채점 AI는 왜 틀렸는지 원인을 짚어준다
- 학생이 스스로 생각하고 발견하게 유도한다

## 경쟁력 (차별점)

**Terry만이 가진 것:**
1. **선생님 + 빌더 동시 보유** — 교육 철학을 직접 AI로 구현
2. **20년 대치동 노하우** — 어디서 막히는지 정확히 앎
3. **듀얼 AI 워크플로우** — Claude Chat(PM) + Claude Code(Builder)로 빠른 개발

**시중에 없는 것:**
- 서술형 5단계 채점 (계산실수 / 방향오류 / 접근불가 / 정답 / 모범)
- 순방향 태깅 + 역방향 필연관계 풀이봇
- 현직 선생님이 직접 설계한 AI 프롬프트

## 단계별 방향

### 방향 A — 지금 (학원 홍보 + 재원생 혜택)
```
목표: 신뢰 확보 + 학생 모집
수익: 1:1 원격 과외 수업료
AI 도구: 재원생 전용 혜택으로 포지셔닝
기간: 현재 ~ 6개월
```

### 방향 B — 중기 (외부 공개 + 구독)
```
목표: 재원생 검증 완료 → 외부 공개
수익: 월 구독료 (9,900 ~ 29,900원)
조건: 재원생 피드백으로 도구 완성도 확보 후
기간: 6개월 ~ 1년
```

### 방향 C — 장기 (B2B 선생님용)
```
목표: 다른 수학 선생님들이 쓰는 플랫폼
수익: 선생님 월 구독 (3만원 × 100명 = 300만원)
조건: 방향 B에서 도구 검증 완료 후
기간: 1년 이후
```

## 의사결정 기준

새 기능을 기획할 때 아래 질문에 모두 "예"여야 진행한다.

```
1. 교육 철학에 맞는가?
   (학생이 스스로 생각하게 돕는가? 정답을 그냥 주는 건 아닌가?)

2. 현재 단계(방향 A)에 맞는가?
   (지금 필요한 건가, 아니면 나중에 해도 되는가?)

3. 1인 운영 가능한 복잡도인가?
   (Terry 혼자 유지보수할 수 있는가?)

4. 학생 신뢰를 높이는가?
   (이 기능이 학부모/학생에게 "이 선생님 믿을 수 있다"는 신호를 주는가?)
```

## 하지 않을 것 (Anti-goals)

- ❌ 광고 수익 모델 (신뢰 훼손)
- ❌ 정답을 바로 알려주는 AI (교육 철학 위반)
- ❌ 과도한 기능 추가 (1인 운영 불가)
- ❌ 상위권 학생 배제 (방향 A에서는 가리지 않음)
- ❌ 대면 수업 (원격 전문으로 포지셔닝)
